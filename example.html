🧮 exp4j TypeScript Port - Browser Example

A mathematical expression evaluator ported from Java to TypeScript

Interactive Calculator

Examples

Simple arithmetic: 3 + 4 * 2
Trigonometry: sin(x) + cos(y)
Logarithm: log(x) + sqrt(y)
Power: 2^8 or x^2 + y^2
Complex: sqrt(a^2 + b^2) * sin(theta)

Supported Functions

sin, cos, tan, asin, acos, atan, sinh, cosh, tanh, log (natural log), log10, log2, sqrt, cbrt, abs, ceil, floor, exp, expm1, and more!

Operators

+ (addition), - (subtraction), * (multiplication), / (division), ^ (power), % (modulo)
